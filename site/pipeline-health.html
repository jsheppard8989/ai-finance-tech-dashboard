Episodes to process (Clawbot todo)

Every current-month episode from your feeds that should end up on the Main Insight column, with a status that tells Clawbot what to do next.

How to clear this list:
  • Needs download: ensure curate.py has run; auto-download will attach audio or log a failure.
  • Needs analysis: run transcript analysis (podcasts) so episodes enter the database.
  • Needs insight: run the insight promotion step so each analyzed episode gets a Latest Insight card.
  • Needs export: run website export + push so new insights are on the live site.
  • Complete: nothing to do; episode is fully on site.
